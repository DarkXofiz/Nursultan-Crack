# Security policy

## Reporting
Do not publish credentials, access tokens, private logs, or exploit details in an issue.
Report suspected vulnerabilities privately to the repository maintainer.

## Project rules
- Never read browser, launcher, Discord, or Minecraft credential stores.
- Never transmit authentication tokens or personal files.
- Never execute operating-system shell commands from the mod.
- Any network feature must have a documented purpose, explicit user-visible behavior,
  and a narrowly scoped endpoint.
- Review third-party mods separately; this project cannot certify their safety.
